# Andreas Asplund — Portfolio

Personal developer portfolio built with React and Vite.

## Focus

The portfolio highlights:
- Fullstack thesis work for Karolinska
- Frontend development during a six-month internship at Hitract
- An independent Raspberry Pi dashboard
- Additional backend and team projects

## Tech

React, JavaScript, CSS and Vite.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```
